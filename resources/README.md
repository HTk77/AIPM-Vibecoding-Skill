# 收藏夹

平时翻到、用过觉得值得回头再看的 GitHub 仓库,陆续在加。
顺序按主题分,没有特别的优先级。

---

## AI PM 方法论

- [dend/awesome-product-management](https://github.com/dend/awesome-product-management)
  PM 通用资源总集,老牌 awesome list。找方法论的时候有地方翻。
- [deanpeters/Product-Manager-Skills](https://github.com/deanpeters/Product-Manager-Skills)
  用 Skill 形式封装 PM 工作流,方向跟我自己在做的接近,参考它的目录组织。
- [deanpeters/product-manager-prompts](https://github.com/deanpeters/product-manager-prompts)
  同作者的 prompt 资产库,配合上面那个 Skill repo 一起看。
- [Shubhamsaboo](https://github.com/Shubhamsaboo)
  Google Cloud 那边的 AI PM,Agent 教程写得很扎实,主页本身就值得关注。

## LLM 与 Prompt 工程

- [Hannibal046/Awesome-LLM](https://github.com/Hannibal046/Awesome-LLM)
  找 LLM 相关的论文 / 工具 / 模型,先翻这个。
- [dair-ai/Prompt-Engineering-Guide](https://github.com/dair-ai/Prompt-Engineering-Guide)
  Prompt / Context Engineering 的事实教材。要给团队同事普及的时候直接发链接。
- [anthropics/claude-cookbooks](https://github.com/anthropics/claude-cookbooks)
  Anthropic 官方,Claude API 各种用法的 notebook。Tool Use / Sub-agent 那几节最常翻。

## AI 应用与 Agent

- [Shubhamsaboo/awesome-llm-apps](https://github.com/Shubhamsaboo/awesome-llm-apps)
  100 多个能直接跑起来的 Agent / RAG / MCP 模板,找参考实现最快的地方。
- [kaushikb11/awesome-llm-agents](https://github.com/kaushikb11/awesome-llm-agents)
  Agent 框架的横向对比。选型时候用。
- [InftyAI/Awesome-LLMOps](https://github.com/InftyAI/Awesome-LLMOps)
  真要上生产的时候再翻。日常用不到。

## Vibe Coding 周边

- [taskade/awesome-vibe-coding](https://github.com/taskade/awesome-vibe-coding)
  Taskade 维护,Vibe Coding 这条线的资源总集。
- [jqueryscript/awesome-claude-code](https://github.com/jqueryscript/awesome-claude-code)
  Claude Code 周边生态(GUI / plugin / 工作流增强工具)。
- [bradAGI/awesome-cli-coding-agents](https://github.com/bradAGI/awesome-cli-coding-agents)
  Aider、Codex、Gemini CLI 这些命令行 Agent 的对比目录。
- [Prat011/awesome-llm-skills](https://github.com/Prat011/awesome-llm-skills)
  看 Skill 这个抽象在生态里铺开成什么样,顺便观察其他作者的命名 / 触发词写法。
