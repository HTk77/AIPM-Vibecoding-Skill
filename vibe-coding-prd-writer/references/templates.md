# Vibe PRD 模块填空模板

> 每个模块的填空骨架。AI 写 PRD 时按此结构填,**不要凭空发挥结构**。
> 每个 `<...>` 是占位符,必须根据项目实际信息填具体内容(不许保留占位符)。

---

## 模板使用注意

1. **占位符不许残留** —— `<...>` 不是文档的一部分,必须根据项目填具体内容
2. **不适用的部分允许删除** —— 例如功能产品删 AI 三要素,但不能减少必填项
3. **代码块不许散文化** —— 数据 schema / API / 模型配置 永远用代码块
4. **表格优先于段落** —— 字不如表,表不如图
